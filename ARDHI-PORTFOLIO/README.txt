ARDHI. — Personal Portfolio
===========================

STRUKTUR FOLDER
ARDHI-PORTFOLIO/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.txt

CARA MENJALANKAN DI VS CODE
1. Ekstrak ZIP.
2. Buka VS Code, pilih File > Open Folder.
3. Pilih folder ARDHI-PORTFOLIO.
4. Klik kanan index.html > Open with Live Server.
5. Jika belum ada, pasang ekstensi Live Server dari Extensions.

CARA MENGEDIT
- Konten dan struktur: index.html
- Warna, layout, dan tampilan: css/style.css
- Animasi dan interaksi: js/script.js

CATATAN
- Playlist Spotify tertanam di index.html.
- Gunakan struktur folder ini agar tautan CSS dan JavaScript tetap berfungsi.
- Arsip ini berasal dari versi tersimpan terakhir. Perubahan lokal yang belum dikirim ke chat tidak termasuk.
